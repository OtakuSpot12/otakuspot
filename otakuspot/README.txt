OTAKUSPOT — ACTUALIZACIÓN CON FOTOS DE REFERENCIA

Incluye fotos de referencia enlazadas desde fichas oficiales de POP MART para los productos mostrados. Las imágenes se sirven desde los servidores de la tienda y podrían cambiar o dejar de mostrarse.

Las categorías Mangas y Accesorios están marcadas como Próximamente hasta agregar productos reales a esas secciones, para evitar que el filtro muestre productos incorrectos.

Para publicar: en GitHub, Add file > Upload files, sube este index.html a la raíz y confirma con Commit changes.

Los enlaces son directos, no afiliados; no generan comisiones.
